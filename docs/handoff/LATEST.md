**Three failed attempts before the working one — all instructive, kept here so nobody repeats them:**

3. **postConversion, `body_text`, reading `pokemonweaknessesraw`/`pokemonresistancesraw` metadata, but with `.decode('utf-8', errors='ignore')` on the read.** `body_text.read()` is already a `str` (see #1) — calling `.decode()` on a `str` throws `AttributeError`, caught silently by the broad `except`. Found via `document.log()` instrumentation, not guessing.
